# Data Files

Here dwells a big bunch of files… some of which are explained below.
Note that it's *not* a mistake if any or all of the files in question
are missing from this repo! Aside 3rd party custom `.dta` files,
**Bill Seurer's MakeChar** is/was shipped with all the essential ones.

## `.DTA` and `.GEN` Files

These are for most part unmodified (or very close so) `DTA` files used by
*Bill Seurer's* **MakeChar** MS-DOS era.

## `test*.*` Files

Various functional and intentionally dysfunctional test files for **dta2json**…

## `gch.manifest` and `gch-*.json` Files

Ready-to-use data files produced by **dta2json** with `--auto` flag.
